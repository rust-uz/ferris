💻 ferris-cli — Terminal Vositasini O'rnatish

Linux, macOS va Windows tizimlari uchun universal paketlar va binar yig'ilmalar (v0.2.0)

⬇ Linux x86_64 📦 .deb (Ubuntu/Debian) 🦀 Crates.io v0.2.0
$ curl -fsSL https://ferris.uz/install.sh | sh

Binar SHA-256 xesh tekshiruvi bilan avtomatik /usr/local/bin/ferris (yoki ~/.local/bin/ferris) ga xavfsiz o'rnatiladi.

$ brew install https://ferris.uz/downloads/ferris.rb

macOS (Apple Silicon M1-M4 & Intel) va Linuxbrew uchun to'liq avtomatik formula.

$ yay -S ferris-cli-bin

Yoki manbadan yig'ish uchun: paru -S ferris-cli

$ curl -fsSLO https://ferris.uz/downloads/ferris-cli_0.2.0_amd64.deb && sudo dpkg -i ferris-cli_0.2.0_amd64.deb

Debian, Ubuntu, Linux Mint va Pop!_OS tizimlariga rasmiy paket boshqaruvi bilan o'rnatish.

use tokio::time::{sleep, Duration};

#[tokio::main]
async fn main() {
    println!("🦀 Ferris: Tokio dvigateli ishga tushdi...");
    
    let handle = tokio::spawn(async {
        sleep(Duration::from_millis(50)).await;
        "⚡ 10,000+ so'rovlar nol GC pauzalarisiz bajarildi!"
    });

    let result = handle.await.unwrap();
    println!("{}", result);
}
